# Introduction

## Navigation

You can navigate paragraphs and pages using the keyboard arrow keys, or VIM style navigation, if you know what that is. While a media is selected, the "enter" key will open the media, and the "left arrow" key will navigate you back to the previously selected element.

On mobile, you can use the "down arrow button" on the bottom right side of the content.
